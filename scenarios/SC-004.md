# SC-004: Windows Application Log Clearing

## Objective

Clear the Application log on an authorized lab endpoint and check
whether Windows records the clearing action and Wazuh detects it.

## ATT&CK Technique

T1070.001 — Indicator Removal: Clear Windows Event Logs

## Prerequisites

- Windows lab endpoint `win-client`
- Active Wazuh agent
- Windows System-channel collection
- An elevated PowerShell session
- A disposable environment with no required Application-log evidence

## Test Procedure

Clear the Application log using `wevtutil.exe` and inspect endpoint
and Wazuh evidence around the test time.

## Original Prediction

- Sysmon Event ID 1 might capture `wevtutil.exe` process creation,
  depending on the active configuration.
- Windows Event ID 104 would record the clearing action.

The original scenario incorrectly placed Event 104 in the Application
channel. In the documented run, it appeared in the **System** channel.

## Observed Outcome

- The Application-log clearing command completed successfully.
- Event ID **104** from **Microsoft-Windows-Eventlog** appeared in
  the **System** channel.
- The event identified **Application** as the cleared log.
- Wazuh rule **63104**, level **5**, detected the action.
- The observed alert mapped to parent technique **T1070**, not the
  predicted sub-technique T1070.001.

Sysmon process-create coverage is not claimed as a verified result
of this investigation.

## Interpretation and Limitations

The alert correctly detected my authorized log-clearing test.
It does not establish malicious intent.

The result demonstrates coverage of the tested standard log-clearing
method. Other ways of manipulating log files were not tested.

## Cleanup and Safety

No persistence was created, but clearing the log deletes its existing
records. Those records cannot be recovered without a prior backup.

- Run only on an authorized, disposable lab endpoint.
- Preserve any needed evidence before testing.
- Do not clear production, Security, or Sysmon logs for this scenario.
- Use a snapshot or backup if the previous state must be recoverable.
